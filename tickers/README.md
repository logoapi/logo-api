# Tickers

One SVG per stock ticker, a CC0 sample of the catalog (50 tickers). Same files as `logos/`, under predictable names. This is not the full list: every ticker in `index.json` (6,562) is served from `https://logoapi.sh/ticker/<SYMBOL>.svg`.

Raw URL pattern:

`https://raw.githubusercontent.com/logoapi/logo-api/main/tickers/<SYMBOL>.svg`

Example: `https://raw.githubusercontent.com/logoapi/logo-api/main/tickers/AAPL.svg`

For any ticker not here, use `https://logoapi.sh/ticker/<SYMBOL>` (free, no key) or the square icon `https://logoapi.sh/icon/ticker/<SYMBOL>`.
